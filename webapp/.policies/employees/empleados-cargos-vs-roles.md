# Nomenclador de cargos vs Control de Roles

## Nomenclador de cargos (Gestión de Empleados)
- Crear / renombrar cargo
- Asociar cargo → **rol existente** (solo selección)
- No crea, elimina, desactiva ni modifica roles
- No asigna permisos de UI

## Control de Roles / Usuarios
- Administración de roles y permisos
- ACL de pantallas

Empleados y nomenclador **consumen** roles; no los administran.
